# v1.0.0-preview.6: Go, Rust and C/C++ receivers

This source preview adds **receivers in Go, Rust and C/C++** that verify the same Spaces proofs as the TypeScript SDK, with no Node runtime or WASM loader. It is for consumers such as bitmachine (#39, #42).

| Language | Where | How to depend on it |
|---|---|---|
| Go | `core/go` (#41) | `github.com/Bitspark/thesmos/core/go@v1.0.0-preview.6` (tag `core/go/v1.0.0-preview.6`) |
| Rust | `core/rs`, crate `bitspark-thesmos` (#43) | git dependency at tag `v1.0.0-preview.6` |
| C and C++ | `core/cpp`, the Rust receiver behind a C ABI with a header-only C++20 wrapper (#44) | CMake `add_subdirectory` or FetchContent with `SOURCE_SUBDIR core/cpp` at tag `v1.0.0-preview.6` |

Each receiver embeds the frozen law as data and delegates checking to Logos's checker in its language (Logos contract 0.24.0, Ontos 0.13.0, archon 0.16.0). Each passes the frozen corpus `law/conformance.ontos` (53 cases) and the Archon-signed proof written by the TypeScript SDK. Independent differential reviews compared 9,763 inputs between Go and TypeScript and 62,368 decisions per language between Rust, Go and TypeScript, with no differences. Building any of them needs read access to the private Bitspark/logos repository; see the README. The release attaches no prebuilt library, so that no archive bundles private dependency code.

The npm package also lets a proof-producing host select its Logos search implementation (`search`, #37). Its dependencies are unchanged from preview.5. The frozen revision-3 law, all eight frozen artifacts, the native proof format and remote contract v1 are unchanged.
