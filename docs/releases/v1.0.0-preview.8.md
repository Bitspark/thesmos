# v1.0.0-preview.8: on npm, crates.io and PyPI

This source preview is the first that thesmos's release workflow publishes to all three package registries at its release: **npm** with provenance, **crates.io**, and **PyPI** with attestations. Each registry trusts the workflow through OIDC, so no registry token is stored (#59, #12). Its receivers, the frozen law and the proof format are those of preview.7.

| Language | How to depend on it |
|---|---|
| TypeScript | `npm install @bitspark/thesmos`, which installs `1.0.0-preview.8` |
| Go | `github.com/Bitspark/thesmos/core/go@v1.0.0-preview.8` (tag `core/go/v1.0.0-preview.8`) |
| Rust | `thesmos = { package = "bitspark-thesmos", version = "=1.0.0-preview.8" }`, from crates.io |
| C and C++ | CMake `add_subdirectory` or FetchContent with `SOURCE_SUBDIR core/cpp` at tag `v1.0.0-preview.8` |
| Python | `pip install --pre bitspark-thesmos`, which installs `1.0.0rc8`. There are abi3 wheels for CPython 3.10 and later on Linux x86_64 and aarch64 (manylinux2014), macOS universal2 and Windows x64, and an sdist that builds with Rust 1.96 on other platforms |

**Changes since preview.7**
- **Registry publishing** (#59).
  - `release.yml` builds the Python wheels and the sdist from the release commit, and runs each against the TypeScript-signed Archon proof.
  - Behind the `release` environment, it publishes the release's exact npm archive, the crate and the Python distributions.
  - Its verify step installs from each registry anonymously, checks that npm serves exactly the attached archive, and runs the Archon proof with each.
  - The same workflow also published preview.7 to npm and crates.io (run 42459087199).
- **Python builds that download nothing anonymously from GitHub** (#62).
  - The wheels and the sdist are built with maturin 1.15.0 from PyPI and Rust 1.96.0 from rustup.
  - The Linux wheels and the sdist are built and tested inside the manylinux2014 images, on those images' own CPython: 3.10 and 3.13 for the wheels, 3.10 for the sdist.
  - Why: on 8 November GitHub's release-asset downloads timed out for anonymous clients, and maturin-action downloads maturin anonymously. That stopped the first release run of this version (run 42468347664) before its approval, with nothing published.
- **Install instructions:** the README and `docs/languages.md` describe installing from the registries.

The receivers, the frozen revision-3 law, all eight frozen artifacts, the native proof format, remote contract v1 and every dependency are unchanged from preview.7.

**Qualification**
- **Receivers:** every receiver job ran every step in [run 42459775902, attempt 1](https://github.com/Bitspark/thesmos/actions/runs/42459775902) on the PR head `a4217fb`, with no Logos token.
  - TypeScript: 119 tests.
  - Go: both packages ok, with all modules verified.
  - Rust: 7 + 1 tests on Windows, Linux and macOS.
  - C/C++: ctest 2 of 2 on Linux and macOS.
  - Python: 21 tests on Windows, Linux and macOS, each with CPython 3.10 and 3.13.
  - Differential: 1,620 cases for each of two seeds, with TypeScript, Go, Rust, Python and C++ deciding every one alike.
  - Consumer builds: Go, Rust, Python and C++ each accepted the Archon proof after 28 checked steps and denied it with one changed byte.

  Since that commit the release commit changes only docs (these notes, `README.md`, `CONTRIBUTING.md` and `docs/languages.md`) and the Python build jobs of `release.yml`, so its `core/` tree is identical.
- **npm package:** the archive is the `thesmos-package` artifact that check.yml built and tested from the release commit. `release-manifest.json` names that run, the qualifying run and the archive's SHA-256, and `SHA256SUMS` covers both files.
- **Release:** made by the `release` workflow. It checked the qualification above through the API, and ran at the release commit so that npm's provenance and PyPI's attestations name it. It ends by verifying the tags (including through proxy.golang.org) and by installing anonymously from each registry.
